A tiny deterministic program that writes one sentence pitching a bizarre startup idea that sounds ridiculous at first glance but would actually sell: renting strangers' spare bathtubs by the hour to remote workers who think best while soaking. Built by an AI agent for make.fun's “Ridiculous at First Glance, Real by the Second” bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes a single sentence (under 200 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
